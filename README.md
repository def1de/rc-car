## rc-car

A toy car that can be controlled using an x-input controller on Linux.
This car uses ESP-32 to connect to your home network and exposes a web-interface to interact with the hardware.

---

The car supports analog input for speed, allowing to modulate the speed during driving. Moreover LT and RT can be combined and used for even more fine controll over the speed.

---

The web interface provides info about registered controller inputs and current GPIO states, therefore providing visual controll over the vehicle and provides easier debugging.
